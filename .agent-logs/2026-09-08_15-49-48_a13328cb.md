You can configure the API key in **two places**:

## 1. Environment file (recommended — server-side)

```env
# --- existing ---

POLLINATIONS_API_KEY=your_api_key_here

JSON2VIDEO_BASE_URL=https://api.json2video.com/v1
JSON2VIDEO_API_KEY=your_json2video_api_key_here

# --- defaults ---
DEFAULT_IMAGE_MODEL=flux
DEFAULT_VIDEO_MODEL=json2video
```

After saving, restart the FastAPI server for the change to take effect.

## 2. Per-request header (client-side)

If you don't set it in `.env`, you can pass it in every request via the `X-API-Key` header:

```bash
curl -X POST "http://localhost:8000/inference/video" \
  -H "X-API-Key: your_json2video_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "a cat walking in space", "duration": 5}'
```

The provider checks the header first, then falls back to the `.env` value. If neither is set, it returns:

```json
{"success": false, "data": null, "error": "JSON2Video API key is required..."}
```
