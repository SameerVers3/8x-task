The inference server is a **FastAPI relay** that routes image generation requests to providers like Pollinations.ai. Here's how to run it:

## Quick Start

```bash
cd inference

# 1. Create virtual environment (first time only)
python -m venv .venv
source .venv/bin/activate

# 2. Install dependencies (first time only)
pip install -r requirements.txt

# 3. Configure environment
cp .env.example .env

# 4. Run the server
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

## Available Endpoints

Once running, the API is available at:

| Endpoint | Description |
|----------|-------------|
| `GET /` | API info |
| `GET /health` | Health check + provider status |
| `GET /docs` | Swagger UI |
| `GET /inference/models` | List available models |
| `GET /inference/providers` | List registered providers |
| `POST /inference/image?model=flux` | Generate an image |

## Generate an Image (Example)

```bash
curl -X POST "http://localhost:8000/inference/image?model=flux" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your_api_key" \
  -d '{
    "prompt": "a cat in space wearing an astronaut helmet",
    "width": 1024,
    "height": 1024,
    "seed": 42,
    "negative_prompt": "blurry, low quality",
    "nologo": true,
    "private": false
  }'
```

## Supported Image Models

- `flux` — default high-quality model
- `turbo` — fast generation
- `any-dark` — optimized for dark themes

All three are free-tier via Pollinations.ai (no API key required for basic usage).

## Run Tests

```bash
pytest tests/ -v
```
