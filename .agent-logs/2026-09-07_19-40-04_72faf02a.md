## 🗄️ Database Schema (Neon PostgreSQL)

| Table | Purpose |
|-------|---------|
| `User` | Users with credits balance |
| `OTP` | Verification codes (10-min expiry) |
| `ModelConfig` | Image/video/enhance models with credit costs |
| `SystemPrompt` | Style prompts (cinematic, anime, etc.) |
| `Creation` | Generated images/videos with status |
| `Revision` | Variations of creations (costs credits) |
| `Enhancement` | Upscale, denoise, restore (costs credits) |
| `CreditTransaction` | All credit changes (audit trail) |
| `GlobalConfig` | App settings (signup credits, limits, etc.) |
