## How to Use


### Generate an image
```bash
curl -X POST "http://localhost:8000/inference/image?model=flux" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your_api_key" \
  -d '{
    "prompt": "a cat in space wearing an astronaut helmet",
    "width": 1024,
    "height": 1024,
    "seed": 42,
    "negative_prompt": "blurry",
    "nologo": true,
    "private": false
  }'
```

## Key Architecture Points

- **Single `InferenceRelay` class** routes all requests — just call `relay.route(task_type, model, payload, api_key)`
- **Provider-per-class** — each provider defines its own `task_type`, `supported_models`, `request_model`, `generate()`, and `format_output()`
- **Adding a new provider**: subclass `BaseProvider`, implement required methods, register in `registry.py` — the relay auto-discovers it
- **API keys** passed via `X-API-Key` header, forwarded to providers that need them
- **Everything configurable** in `.env` — copy `.env.example` to `.env` and customize
- **Video, text, enhancement** are stubbed with request/response models and routes, ready for providers to be added

All `.env` variables, provider configs, and model defaults are externalized and configurable.
