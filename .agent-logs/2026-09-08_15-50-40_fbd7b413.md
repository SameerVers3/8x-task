## App (`/app/.env`)

Your app `.env` already has the skeleton. Here's what's needed for each section:

### Already filled (working)
- `DATABASE_URL` — Neon PostgreSQL (already has a value)
- `JWT_SECRET` — change this for production
- `APP_NAME`, `APP_URL`, `NODE_ENV`
- `INFERENCE_API_URL` — points to your local inference relay (`http://localhost:8000`)
- `SMTP_HOST`, `SMTP_PORT`, `SMTP_SECURE`, `SMTP_USER`, `SMTP_PASS` — for OTP emails (Gmail app password)
- `DEFAULT_SIGNUP_CREDITS` — free credits on signup (default 50)

### What you need to fill in

**Stripe (for payments / demo mode):**
```bash
STRIPE_SECRET_KEY="sk_test_..."        # from Stripe Dashboard → Developers → API Keys
STRIPE_WEBHOOK_SECRET="whsec_..."      # from Stripe CLI or Dashboard → Webhooks
STRIPE_PUBLISHABLE_KEY="pk_test_..."   # used on frontend (check if referenced anywhere)
```

> `STRIPE_PUBLISHABLE_KEY` is in your `.env` but not actually referenced in the code yet. The checkout session route uses only the secret key on the backend. You might need it if you ever add client-side Stripe Elements.

**Cloudflare R2 (for image storage):**
```bash
R2_ACCOUNT_ID="your-account-id"        # from R2 dashboard → Account ID
R2_ACCESS_KEY_ID="your-access-key"     # from R2 → Manage R2 API Tokens → Create API Token
R2_SECRET_ACCESS_KEY="your-secret"     # same token page
R2_BUCKET_NAME="fluid-generations"     # default is fine, or your bucket name
R2_PUBLIC_URL="https://pub-xxx.r2.dev" # public bucket URL (custom domain or R2.dev)
```

**Optional:**
```bash
ADMIN_EMAILS="you@example.com,admin@example.com"  # comma-separated admin emails
```
